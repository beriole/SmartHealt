Ce fichier contient les données exhaustives (JSON, Form-Data, paramètres) pour tester chaque route de l'API SmartHealth sur Postman.

============================================================
                        ⚠️ IMPORTANT ⚠️
- Pour toutes les routes protégées, ajoutez le header :
  `Authorization: Bearer <VOTRE_TOKEN_JWT>`
- Pour les requêtes d'upload (Avatar, Médicament, Pharmacie), utilisez le mode **form-data** dans le Body de Postman, et passez le type de la clé de "Text" à "File" pour uploader l'image.
============================================================

### 4. MEDICAMENTS (`/api/medicaments`) - (Réservé PHARMACIEN)

**GET /api/medicaments**
- Parcourir le catalogue global. Params : `?recherche=Doli&categorie=antalgique`

**POST /api/medicaments**
- Rôle Requis : `PHARMACIEN`
- Body type : **form-data**
- Clé texte : `nom_commercial` = Doliprane
- Clé texte : `dci` = Paracétamol
- Clé texte : `forme_galenique` = comprime
- Clé texte : `dosage` = 1000mg
- Clé texte : `categorie` = antalgique
- Clé texte : `est_generique` = false
- Clé texte : `necessite_ordonnance` = false
- Clé texte : `prix_indicatif_fcfa` = 1500
- Clé fichier : `image` = (Sélectionnez le fichier image de la boîte)

**PUT /api/medicaments/:id**
- Même principe en `form-data` pour la mise à jour par les pharmaciens.

### 5. PHARMACIES (`/api/pharmacies`)

**POST /api/pharmacies** (Par le PHARMACIEN ou ADMIN)
- Body type : **form-data**
- Clé texte : `nom_pharmacie` = Pharmacie du Grand Marché
- Clé texte : `numero_autorisation` = PHARMA-001
- Clé texte : `adresse` = Yaoundé, Centre-ville
- Clé texte : `latitude` = 3.8480
- Clé texte : `longitude` = 11.5021
- Clé texte : `telephone` = +237222000000
- Clé texte : `livraison_disponible` = true
- Clé texte : `rayon_livraison_km` = 15
- Clé fichier : `image` = (Photo de la façade)
*(Note: Si vous êtes connecté en tant que PHARMACIEN, l'API vous identifiera automatiquement comme le responsable légal, pas besoin de spécifier id_responsable).*

**PUT /api/pharmacies/:id/upload-document** (Réservé PHARMACIEN / ADMIN)
- Body type : **form-data**
- Clé fichier : `document` = (Le scan PDF/Image de l'autorisation ou de l'agrément)

**POST /api/pharmacies/:id/verify** (Réservé ADMIN)
- Body type : **JSON**
```json
{
  "statut_verification": "verifie",
  "notes_verification": "Dossier validé par l'Ordre National"
}
```

**POST /api/pharmacies/:id_pharmacie/employes** (Réservé RESPONSABLE / ADMIN)
- Body type : **JSON**
```json
{
  "email": "assistant@gmail.com",
  "role_employe": "pharmacien_assistant"
}
```

**GET /api/pharmacies/:id_pharmacie/employes** (Réservé RESPONSABLE / ADMIN)
- Lister le personnel

**PUT /api/pharmacies/:id** (Réservé ADMIN ou au PHARMACIEN responsable)
- Body type : **form-data** (Pour changer les horaires ou la vitrine)

**GET /api/pharmacies/:id_pharmacie/evaluate-ordonnance/:id_ordonnance**
- Permet de simuler le coût pour servir une ordonnance dans cette pharmacie.

### 7. GESTION DES STOCKS E-COMMERCE (`/api/stocks`) - (Réservé PHARMACIEN)

**GET /api/stocks/search**
- Accessible à tous. Cherche le produit dans les officines.
- Query : `?medicament=Doliprane&sort=price` ou `sort=rating`

**GET /api/stocks/my-stocks**
- Rôle requis : `PHARMACIEN` (Renvoie tout son propre inventaire).

**POST /api/stocks**
- Rôle requis : `PHARMACIEN` ou ADMIN
- Body type : `raw JSON`
{
  "id_medicament": "UUID_DU_MEDICAMENT",
  "quantite_disponible": 100,
  "prix_vente_fcfa": 2500,
  "seuil_alerte": 20,
  "date_peremption": "2025-12-31T00:00:00.000Z"
}

**PUT /api/stocks/:id_stock**
{
  "quantite_disponible": 85,
  "prix_vente_fcfa": 2400
}

**DELETE /api/stocks/:id_stock**
- Retire définitivement le médicament de la vente dans cette pharmacie.

### 8. COMMANDES ET ACHATS (`/api/commandes`)

**POST /api/commandes** (Achat Panier direct)
- Réservé PATIENT
```json
{
  "id_pharmacie": "UUID_PHARMACIE",
  "type_livraison": "livraison_domicile",
  "adresse_livraison": "Yaoundé, Quartier Mvan",
  "lignes": [
    {
      "id_stock": "UUID_STOCK_MEDICAMENT",
      "quantite_commandee": 2
    }
  ]
}
```

**POST /api/commandes/from-ordonnance** (Panier digital - Patient)
- Transforme une ordonnance digitalisée en achat direct.

**GET /api/commandes/disponibles-livraison** (Livreur)
- Trouve des commandes en cours, sans livreur.

**POST /api/commandes/:id/assigner-livreur** (Livreur)
- Le livreur s'attribue une commande prête en pharmacie. Génère un code PIN secret pour le patient.

**PUT /api/commandes/:id/status** (Suivi de colis - Réservé PHARMACIEN / ADMIN)
- Body type : **JSON**
- Permet de faire progresser le statut d'une commande (en_attente -> preparee -> en_livraison -> livree). Mettez à jour ce statut pour informer le client.
```json
{
  "statut_commande": "en_livraison"
}
```

**POST /api/commandes/:id/valider-livraison** (LIVREUR/PATIENT/ADMIN)
- Valide la réception du colis avec le code PIN remis par le patient. Paie la commission système au livreur.
```json
{
  "code_validation": "8492"
}
```

**POST /api/commandes/:id/evaluer** (PATIENT)
- Permet d'évaluer la livraison et la pharmacie.
```json
{
  "note_livraison": 5,
  "commentaire_livraison": "Hyper rapide, merci.",
  "note_pharmacie": 4,
  "commentaire_pharmacie": "Très beaux packagings mais un peu cher."
}
```

**POST /api/commandes/:id/payer** (Patient via NotchPay)
- Initialise le paiement externe pour la facture.
